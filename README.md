# おしよせ！かいぶつ

草原のむこうから押しよせてくる怪物を、タップで追いかえすゲームです。
1回1分くらいで遊べて、つい「もう1回」となるように作っています。

> もとは「運動でモンスターを倒すダイエットゲーム」でした。登場する4体の怪物の絵は、そのときに描いたものをそのまま使っています。

## 遊び方

1. 「スタート」を押す
2. 奥から歩いてくる怪物をタップしてたおす
3. 怪物が手前の柵まで来ると、ライフ（ハート）が1つ減る
4. **ライフが0** か **玉ぎれ** でゲームオーバー。点数とベストスコアが出る

## ルール

### 玉（球数の制限）
- 玉は最大10発。タップするたびに1発使う（外しても減る）
- 時間がたつと少しずつ戻る（約0.45秒で1発）
- 怪物をたおすと1発戻ってくる
- **玉を使い切ったらゲームオーバー**（最後の1発でたおせば1発もどるのでセーフ）
- 残り3発以下になると、玉の表示が赤く点滅して知らせる

### 怪物

| 怪物 | 特徴 | 点数 |
|---|---|---|
| モチグマ | 2回たたくとたおせる。ぴょこぴょこ歩く | 20 |
| ドカプリン | 1回でたおせるが、足がはやい | 10 |
| ネボスケ竜 | 3回必要。ただし**寝ている間にたたくと一撃**（会心・点数2倍） | 30 |
| オニギリガニ | 横にうろうろしながら来る | 15 |

- まれに**金色の怪物**が出る。点数5倍、たおすとライフが1つ回復する
- ネボスケ竜とオニギリガニは、少し時間がたってから出てくる
- 怪物は横幅いっぱいのいろんな場所から出てくる。出てきたばかりで**うっすらしている間はたたけない**（出てくる場所の連打対策）

### 点数を増やすコツ
- **コンボ**：続けて当てるとコンボがつながり、5コンボごとに点数の倍率が上がる（最大4倍）。外したり、2.2秒たたかなかったりすると切れる
- **フィーバー**：20コンボで7秒間のフィーバー。点数2倍、玉が使いほうだい（うちほうだい）、怪物がたくさん来る。その後は25コンボごとにまたフィーバー。コンボ表示に「フィーバーまであと○」が出る
- **ながれ星**：ときどき空を流れる星をタップすると、画面の怪物を全部たおせる（玉は使わない）
- 25秒ごとにレベルが上がり、怪物が速くなる

### 称号
ゲームオーバーのとき、点数に応じて称号がつきます。
見習いの見張り番 → 村の見張り番（300点）→ 草原の守り手（800点）→ かいぶつハンター（1600点）→ 伝説の門番（3000点）→ 怪物たちの天敵（5000点）

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 画面の土台 |
| `style.css` | デザイン |
| `script.js` | ゲームの動き。いちばん上の「調整しやすい設定」で難しさを変えられる |
| `art.js` | 怪物の絵（SVG） |

- スマホで遊ぶ前提（縦画面）。画面の拡大縮小は止めてあり、やられたときに対応機種ではスマホが震える
- HTML / CSS / JavaScript だけで動きます。ビルド不要
- 保存するのは「ベストスコア」と「音のオン・オフ」だけ（ブラウザの中に保存）
- 文字だけ Google Fonts（M PLUS Rounded 1c）を使っています

### 難しさを変えたいとき
`script.js` の上のほうにある設定を変えます。

- `LIVES` … ライフの数
- `AMMO_MAX` / `RELOAD_SEC` … 玉の最大数と、1発戻るまでの秒数
- `APPEAR_Z` … 出てきたばかりでたたけない距離（大きいほど長くたたけない）
- `FEVER_COMBO` / `FEVER_TIME` … フィーバーになるコンボ数と長さ
- `LEVEL_SECONDS` … レベルが上がる間隔
- `TYPES` … 怪物ごとの体力・速さ・点数
